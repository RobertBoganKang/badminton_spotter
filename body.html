参数调节

提示：目标点 / 准备点的深度（z）与高度（y），请直接在「侧视图」上下拖动圆点调整；左右（x）在「主视图」拖动。

身体参数

身高会按比例缩放骨骼长度（臂长、肩高、腿长等），并重算画布视野。

关节限位阈值（成人 ROM，可调）

固定项：肘 ≤ 145°、肩上举 ≤ 175°；上举上限随「上举平面」变化：侧 / 前 175° → 身后 50° → 躯干内侧 25°。

出球限位（拍面法线朝向）

法线 = 肩肘 · 肘腕平面法向量；须向前 (+z)，仰角 ∈ [−下, +上]，左右偏角 ∈ [−左右, +左右]。

先投影，再判形状 · 说明

一句话：先算出 3D 解，把 z 丢掉投影到画面，再在 2D 上看肘落在「肩→拍端」连线的哪一侧——下方是正手（L 形），上方是反手（反 L 形）。

一、三步判形状

  1. 步骤 1：3D IK 算出肘和拍端的 3D 坐标
  2. 步骤 2：丢掉 z，把肩 / 肘 / 拍端投影到 2D 画面
  3. 步骤 3：在 2D 画面上，看肘在「肩→拍端」连线的下方（L 形 = 正手）还是上方（反 L 形 = 反手）

判据只看形状，不看左右；正手 / 反手都能覆盖左右两侧。画布上画出肩→拍端淡灰虚线，并用竖直虚线标出肘到连线的垂足，直观看到判据。深度 z 现在在侧视图中拖动调整。

二、关节限位（默认开启）

在 3D IK 之后再加一道人体活动范围（ROM）检查，剔除「连杆够得到、但关节做不到」的假可达姿势。

完整成人上肢 ROM（主动活动度：AAOS 标准值 / 中文康复量角器标准表 / PMC 上肢 ROM 表；躯干固定的模型取偏保守一档）：

  • 肘 屈曲 ≤ 145°（140–150），过伸 0°（不能反折）；外翻 0–15 / 内翻 0–10（模型无此自由度）
  • 肩 外展 / 前屈 ≤ 175°（0–180）、后伸 ≤ 50°（0–50/60）、内收（过中线）≤ 25°（0–20/30）
    ——本模型合成一条「上举上限随上举平面变化」：在正侧（外展面）/ 正前（前屈面）可到 175°，转到正后（后伸面）只剩 50°，转到正对躯干内侧（内收面）只剩 25°，中间线性插值。这条就是「正手大臂不可能伸到左下角」的根因：往躯干一侧（−x）越偏，允许的上举角越小
  • 肩 内旋 ≤ 90° / 外旋 ≤ 90°（绕上臂轴量「前臂方位」；中立位 = 上臂垂下、屈肘 90°、前臂指向前方，上臂上举时中立位跟着转）。手垂在身体下方而肘却甩到身前 / 身后，或低位正手要极度内旋才够得到，都会被这条剔掉
  • 水平内收 0–135、水平外展 0–30；前臂旋前 / 旋后各 0–80（由「出球限位」的拍面朝向体现）；腕 背伸 70 / 掌屈 80 / 桡偏 20 / 尺偏 30（腕+手并为刚体，未建）

三、躯干碰撞（默认开启）

躯干按 x ∈ [−0.40, 0]、深度 ±0.14 m 的椭圆柱建模，肩→肘、肘→腕任一段穿入身体即剔除；它与「肩内收 ≤ 25°」配合，把左下（跨过身体）那一整片假可达区域删掉。

取消勾选可与无限制版对照。热力图只显示有解（可达）的区域，其余位置保持透明。

四、出球方向限位（默认开启）

拍面法线 = 「肩→肘」与「肘→腕」两直线所构成平面的法向量（= 上臂方向 × 前臂方向，取朝前 +z 一侧）。击球点须同时满足三重朝向约束：

  1. 有向前 (+z) 分量；
  2. 朝上 / 朝下（仰角）在 [−30°, +60°] 内；
  3. 朝左 / 朝右（水平偏角）在 ±30° 内。

任一不满足即被剔除。仰角、左右阈值均可调。

  • 侧视图（深度 z–高度）画绿色仰角锥与出球箭头 → 看朝上 / 朝下是否越界
  • 俯视图（左右 x–深度 z）画绿色左右锥与出球箭头 → 看拍面水平朝向是否朝前

五、视图与交互

  • 主视图（左右 x–高度 y）：热力图 + 人体 + 当前手臂姿势；左上角色标面板可任意拖动
  • 侧视图（深度 z–高度 y）：高度与主图严格对齐，标出准备手 / 目标手的前后（深度）位置；上下拖动圆点即可改高度 y 与深度 z
  • 俯视图（左右 x–深度 z）：前 = 上，看拍面法线的水平朝向
  • 初始点 z 独立：准备点的深度用侧视图单独拖动，不再和目标击球点的 z 绑定
  • 双击主视图可显示 / 隐藏侧视图与俯视图；左上角滑块图标打开「参数调节」抽屉；顶部右侧箭头收起 / 展开标题栏

六、身高与镜像

  • 身高滑块（140–200cm）：按比例缩放全部骨骼长度，并重算画布可达视野
  • 左右镜像：仅翻转显示。正手/反手的求解不变，但屏幕上的形状标签会 L↔反 L 互换（因为左右翻转过）

In one sentence: solve the 3D IK first, drop z to project onto the picture, then look at which side of the shoulder→racket line the elbow falls on — below = forehand (L-shape), above = backhand (anti-L).

1. Three steps to classify

  1. Step 1: 3D IK computes the 3D coordinates of the elbow and the racket end.
  2. Step 2: drop z, project shoulder / elbow / racket end onto the 2D picture.
  3. Step 3: on the 2D picture, look at whether the elbow is below the shoulder→racket line (L = forehand) or above (anti-L = backhand).

The rule only depends on shape, not left/right; both forehand and backhand cover both sides. The canvas draws the shoulder→racket dashed line and a vertical dashed line from the elbow to its foot of perpendicular, so the rule is visible. Depth z is now adjusted by dragging in the side view.

2. Joint limits (on by default)

After the 3D IK, a human range-of-motion (ROM) check is applied to remove "the linkage reaches, but the joint cannot" false-positives.

Full adult upper-limb ROM (active ROM: AAOS values / Chinese goniometry standard / PMC upper-limb ROM; the trunk-fixed model takes the conservative end):

  • Elbow flexion ≤ 145° (140–150), no hyperextension; valgus 0–15 / varus 0–10 (not modeled)
  • Shoulder abduction / flexion ≤ 175° (0–180), extension ≤ 50° (0–50/60), adduction (across midline) ≤ 25° (0–20/30)
    — this model synthesizes one rule: "the elevation cap depends on the elevation plane": 175° in the pure lateral (abduction) / pure front (flexion) plane, only 50° in the pure back (extension) plane, only 25° toward the trunk (adduction) plane, linearly interpolated. This is the root cause of "the forehand upper arm cannot reach the lower-left corner": the more the arm goes toward the trunk side (−x), the smaller the allowed elevation.
  • Shoulder internal rotation ≤ 90° / external rotation ≤ 90° (the "forearm direction" is measured around the humeral axis; neutral = arm hanging, elbow flexed 90°, forearm pointing forward; the neutral reference rotates with the arm when raised). A forearm hanging below the body while the elbow swings forward / backward, or a low forehand that needs extreme internal rotation, is rejected by this rule
  • Horizontal adduction 0–135, horizontal abduction 0–30; forearm pronation / supination 0–80 each (reflected by the "shot-direction limits" on the racket face); wrist extension 70 / flexion 80 / radial deviation 20 / ulnar deviation 30 (wrist + hand treated as a rigid body, not modeled)

3. Trunk collision (on by default)

The trunk is modeled as an elliptical cylinder with x ∈ [−0.40, 0] and depth ±0.14 m. If either shoulder→elbow or elbow→wrist enters the body, the pose is rejected; together with "shoulder adduction ≤ 25°", this deletes the whole lower-left (cross-body) false-reachable region.

Uncheck to compare against the unrestricted version. The heatmap only paints reachable (solvable) cells; everything else stays transparent.

4. Shot-direction limits (on by default)

The racket-face normal = the normal of the plane formed by the shoulder→elbow and elbow→wrist lines (= upper-arm direction × forearm direction, taken on the forward (+z) side). The contact point must satisfy three orientation constraints simultaneously:

  1. has a forward (+z) component;
  2. up / down (elevation) within [−30°, +60°];
  3. left / right (azimuth) within ±30°.

Any violation rejects the point. The elevation and lateral thresholds are adjustable.

  • Side view (depth z–height) draws the green elevation cone and the shot arrow → check the up / down limits.
  • Top view (left–right x–depth z) draws the green azimuth cone and the shot arrow → check the horizontal heading.

5. Views and interaction

  • Main view (left–right x–height y): heatmap + body + current arm pose; the color-bar panel can be dragged anywhere
  • Side view (depth z–height y): height pixel-aligned with the main view, showing the front/back (depth) position of the ready / target hands; drag the dots up/down to change height y and depth z
  • Top view (left–right x–depth z): forward = up, shows the horizontal heading of the racket-face normal
  • Ready-point z is independent: its depth is dragged separately in the side view, no longer bound to the target contact z
  • Double-click the main view to show / hide the side view and top view; the slider icon at top-left opens the "Parameters" drawer; the arrow at top-right collapses / expands the header

6. Height & mirror

  • Height slider (140–200cm): scales all bone lengths proportionally and recomputes the reachable canvas view
  • Mirror: visual only. Forehand/backhand solving stays the same, but the on-screen shape labels swap L↔anti-L (since left/right is flipped)
