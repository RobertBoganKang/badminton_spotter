落点推荐 · 计算原理

一句话：在对方半场所有合法落点里，找一个让对手最难接到的点。单打额外扣掉“我方打完能不能回中场”的代价；双打只算对手难度。对手可以静止，也可以带初速度。

一、场地与坐标系

  • 单打场地：长 L = 13.40 m、宽 W = 5.18 m，球网位于 y = 6.7 m
  • 合法落点区域：|x| ≤ 2.39，0.2 ≤ y ≤ 13.2

二、双击调出速度手柄

双击某个球员点，即可调出该球员的速度手柄（淡蓝色死区圆 + 蓝色手柄）。再双击一次收起手柄并将该球员速度归零。

  • 拖在死区内：速度 = 0
  • 拖出死区外：出现蓝色箭头，长度与速度成正比，上限 6 m/s
  • A、B 两个手柄独立控制，互不影响

三、三方向速度权重

方向权重
横向（x）W_X = 1.0
向前上网（dy<0）W_FWD = 1.15
向后后退（dy>0）W_BACK = 1.7

四、启动修正（平滑版）

k = KADV + (KREV − KADV)·(1 − sigmoid(projDist / S0))

sigmoid 让 k 在投影距离 0 处取中值，往两侧平滑过渡到 0.7 / 1.8。v=0 时 k=1。

五、对手难度

  1. 加权跑动距离 × 启动修正
  2. × 追身加成（距对手 < 0.45 m 时 ×1.6）
  3. × 贴边加成（1 + 1.2·exp(-b/0.3)）

六、热力图

每格颜色 = min(tA, tB) 的等效时间（含启动修正）。偏蓝快、偏红慢。

七、总评分 J

  • 单打：J = 对手难度 − 0.3 × 到 (0, 3.35) 的距离
  • 双打：J = min(难度A, 难度B)

红点标签旁用方括号显示 J 值，如「最优[12.3]」，四角次优同理标「2[11.8]」。四角分数从全局网格筛选，数学上保证不超过红点分数。

八、等难度线与结合部

「到 A 和到 B 难度相等」的分界线用 marching squares 数值追踪。结合部 = 沿垂直两人连线分两侧，每侧取 min(难度A, 难度B) 最大的点。两人距离 < 1.0m 时该线不绘制（无意义）。

九、红点与四角次优

红点 = 全场 J 最大。四角次优 = 四个角附近 2 m 内 J 最大（从全局网格筛选，与红点同源），按 J 排序后标 ②③④⑤（① 被红点占用）。

十、可调参数

  • W_BACK / W_FWD：1.7 / 1.15
  • K_REV / K_ADV：1.8 / 0.7
  • S0_DIST：1.5m（平滑过渡宽度）
  • K_BODY：1.6，K_EDGE：1.2
  • W_ME_SINGLE：0.3
  • V_GAMMA：3.0（手柄曲线，越大低速越精细）

十一、局限

  • 双打不评估我方回位
  • 热力图"时间"是等效时间（加权距离），不是真实秒数
  • 只算落点，不管球路
